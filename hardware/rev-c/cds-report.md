# Rev C compliance report

Generated by `cargo run -p cubesat-cad --release -- build hardware/rev-c`. Do not edit by hand.

Checked against the CubeSat Design Specification (CDS) Rev 14.1 (Cal Poly, 2022-02-09), with the processes in NASA's CubeSat 101 (October 2017). "Deviation" marks a requirement a printed classroom frame does not meet; a flight version would need a different material or part, or the launch provider's approval. These are CAD checks: measure the printed parts before relying on them.
