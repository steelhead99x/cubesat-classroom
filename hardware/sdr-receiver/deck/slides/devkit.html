Rev A · dev kit

Built to be taken apart and measured

3 break points

Test each RF block

A 0 Ω link with a U.FL on each side, between antenna, LNA, filters and demodulator.

6 jumpers

Measure every rail

Pull a jumper to put a meter in series with that supply.

1 header

Swap the controller

Fit shunts for the XIAO, or wire another board, like an ESP32-P4, to the odd pins.

Monitor port

See the oscillator

The synthesizer’s second output goes to a U.FL for a spectrum analyzer.

Test points

Probe the baseband

I and Q on a header, plus VTUNE, lock detect and power-down.

5 LEDs

Read it at a glance

Power, 3.3 V, PLL lock, bias tee and a user LED.

Rev A is a learning board. Every stage can be tested on its own, which is what a crew needs to find and fix problems on the first build.
