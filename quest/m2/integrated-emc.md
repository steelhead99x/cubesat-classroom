# [L] Close the integrated EMC requirement

## Goal

Submit applicable electromagnetic compatibility evidence for the agreed configuration and obtain disposition from the provider.

## Plan

Identify emissions and susceptibility conditions, test modes and inhibit state. Record the provider's applicability decision if it assigns documentation instead of a test.

## Required

- [ISS verification plan](/quest/m1/iss-verification-plan.md) - defines EMC applicability, modes and criteria.
- [Deployment inhibit design](/quest/m1/deployment-inhibits.md) - defines the states and associated controls.
