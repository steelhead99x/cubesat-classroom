# [S] Print and measure the PLA case coupon

## Goal

Verify the actual fastener fit before spending time and filament on the enclosure.

## Plan

Print the [M3 fit coupon](/hardware/p1s/01-m3-fit-coupon.3mf) using the reviewed PLA settings. Starting at the notch, the nominal holes are 2.6, 2.8, 3.0, 3.2, 3.5, and 3.8 mm. Record overall size, hole behavior, first-layer swelling and corner lift. Test the intended fastener by hand. Report which opening clears it and which pilot engages without splitting. Stop and document the mismatch if you cannot reproduce the fit. Any change to the shell pilot or lid clearance belongs in a reviewed CAD revision.

## Required

- [P1S case slice review](/quest/m0/slice-p1s-case.md) - provides the documented PLA setup.
