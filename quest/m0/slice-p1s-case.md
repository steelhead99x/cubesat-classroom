# [S] Validate the Rev A case in Bambu Studio

## Goal

Produce a repeatable PLA slice for all three Rev A models on the Bambu P1S. A second builder can confirm the same orientation, nominal sizes and preview checks.

## Plan

1. Open the [P1S test files](/hardware/p1s/README.md). Import the M3 coupon, case shell, and camera lid separately. Record the model revision, Bambu Studio version, actual nozzle, plate, filament preset, layer height, and any overrides.
2. Confirm the sizes against the print guide. The shell should sit floor down with the opening up. The lid should sit exterior face down with the tabs up. Check the first layer, pilot holes, cable slot, tabs and camera opening in Preview.
3. Save a preview screenshot for each model. Record any warning, how you resolved it, and whether each part is ready to print. Keep any unresolved warning visible in the report.
