# [S] Repeat the P1S case fit test

## Goal

Confirm that a second print reproduces the baseline or shows a measurable improvement without introducing a new fit problem.

## Plan

Repeat the affected coupon or case print with the reviewed revision and compare it with the original PLA results using the same measurements. Recheck lid clearance, fastener engagement, and cable and camera fit if the change could affect them. Record model revision, settings, old and new results, and any checks still open. If trying ASA, qualify the coupon first with the filament supplier's profile and keep the ASA results separate from the PLA comparison. Ask a second builder to review the evidence. These results cover bench testing.

## Required

- [Case improvement review](/quest/m0/improve-p1s-case.md) - identifies the reviewed baseline or change to reproduce.
