# [M] Identify an ISS path for printed rails

## Goal

Record a provider contact route, applicable deployer and document revisions, a feasible delivery window, and the provider’s written position on whether it will consider fully printed deployer-contact rails.

## Plan

Use the [ISS deployment review](/docs/iss-deployment-review.md) to ask about the applicable interface agreement and exception process. Record a documented no-go if the provider declines. Keep the P1S-printable mechanical requirement in the decision.
