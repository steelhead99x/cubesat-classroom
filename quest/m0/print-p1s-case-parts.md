# [S] Print the Rev A shell and lid in PLA

## Goal

Print a shell and lid, and record enough that another crew can repeat the print.

## Plan

Print the [case shell](/hardware/p1s/02-case-shell.3mf) and [camera lid](/hardware/p1s/03-camera-lid.3mf) with the same settings as the coupon. After cooling, measure the outside of each part and note any corner lift, cracks or broken tabs. If a print fails, record the settings and a photo of the defect before you retry.

## Required

- [PLA case coupon](/quest/m0/print-p1s-case-coupon.md) - confirms the screws fit.
