# [S] Measure the PLA rail coupon

## Goal

A second builder can reproduce the PLA corner coupon and its measured width, recess and visible defects.

## Plan

Start with the Bambu P1S settings from the slicer review. Record filament lot, nozzle, layer height, orientation, support removal, measured dimensions and corner lift. Keep the measurements tied to Rev B.

## Required

- [P1S slice review](/quest/m0/slice-rev-b.md) - provides the documented PLA print setup.
