# [M] Compare a balloon bench log with flight data

## Goal

A student crew records a bench reference and a deliberate input failure, then plots both pressure and temperature, leaving data gaps visible. A teacher verifies the result against the [balloon lab](/docs/balloon-lab.md).

## Plan

Record sensor model and calibration, the clock basis, plotted units, sample count and missing data. Include an example plot or a small consent-cleared CSV.
