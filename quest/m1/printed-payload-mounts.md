# [M] Design printable payload and harness mounts

## Goal

A selected sensor board, camera option and harness fit in printed mounts with clearances and retained routing shown in CAD.

## Plan

Use actual component drawings and mark the load paths, service access and stowed envelope. Record a bench fit test with the intended components or dimensionally verified surrogates.

## Required

- [Printed chassis and rails](/quest/m1/flight-rail-cad.md) - provides the structure and internal envelope.
