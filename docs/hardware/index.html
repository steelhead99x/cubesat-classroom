AMSAT CubeSatSim fork · Arduino payload

CubeSat CAD and print files

Build a real 1U frame: AMSAT's CubeSatSim frame with a printed plate for an Arduino Uno R3 and Nano 33 BLE Sense. Every part is printed, with no screws, nuts or metal standoffs. Print the test coupons first to check your printer's fit.

Verification status

Almost verified

We're nearly done verifying this AMSAT-forked design. Its design checks run on every change; the last print-and-fit checks are wrapping up. This is the only version we publish here. Until verification is finished, print the test coupons first and report what you find.

Current build · AMSAT frame kit

Print the 1U frame and payload

Three Bambu Studio projects, each part already in print orientation. Use PLA, the 0.20mm Standard process for your nozzle, and supports off. No screws, nuts or metal standoffs.

Test coupons (3MF)
Print first. A snap pin with its flex-finger tab, and a board hook and lip with a strip of test board: a few grams of plastic to check your printer.
Frame and payload kit (3MF)
Two plates: the payload plate and the bottom piece with snap columns, then both AMSAT sides (one with the camera hole) and the unchanged AMSAT top.
Fit plate (optional) (3MF)
An open-truss version of the payload plate with the same board mounts, to check both boards with less plastic.
Assembly steps and fit checksSTL files for other slicers

Mission patches

Every lesson's patch is a flat three-colour print, about 75 × 73 mm, for a multi-colour printer or two filament changes. Print the test coupon first.
