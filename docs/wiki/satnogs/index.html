SatNOGS

An open-source, worldwide network of volunteer satellite ground stations.

Also called: Satellite Networked Open Ground Station, Libre Space Foundation

SatNOGS (Satellite Networked Open Ground Station) is an open-source project of the Libre Space Foundation. Volunteers run low-cost ground stations around the world, and a shared network schedules them to record satellite passes and publish the data.
