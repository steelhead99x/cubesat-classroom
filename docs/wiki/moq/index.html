Media over QUIC (MoQ)

An IETF protocol for live media and data that fans out through relays.

Also called: MoQ, Media over QUIC, MoQ relay, track, fan-out

Media over QUIC (MoQ) is a protocol being developed at the IETF for sending live media and data with low delay. A publisher sends named tracks (for example telemetry.v1) to a relay, and the relay fans each track out to every subscriber, so one stream in can serve many classrooms out. MoQ runs on QUIC.

CubeSat Classroom uses MoQ to share each satellite pass from a ground station with every classroom.
