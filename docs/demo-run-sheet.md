# Five-minute classroom demo

Before the demo, open [Make first contact](https://cubesatclass.org/quests/first-contact/) in a browser tab. If showing the local Rust station, run the [quick start](quick-start.md) beforehand and leave its terminal open. Have the [CAD page](https://cubesatclass.org/hardware/) or a labelled bench print ready.

| Time | Show | What to look for |
| --- | --- | --- |
| 0:00 | Request a sensor reading. | Ask the audience to read one value and its unit. Point out the simulation label. |
| 1:00 | Start the test camera. | Count the eight frames in a complete run. |
| 2:00 | Start a second run and pause contact after the first frame. | Compare the partial frame count with the first run. Restore contact and request a fresh reading. |
| 3:30 | Show the case files or your print. | Point to the P1S fit coupon, the camera opening, and one dimension you plan to check. State which fit checks have been run. |
| 4:30 | Ask what to test next. | Record one observation or let a teacher choose a [quest](../quest/README.md). |

If the local station is unavailable, use the browser station for the whole demo. If you have no connection, use a local station that has already passed the [offline rehearsal](../quest/m0/demo-offline-rehearsal.md).

The demo uses simulated readings and test video. Label any fixture or physical measurements as you show them.
