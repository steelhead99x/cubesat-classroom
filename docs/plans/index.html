Guardrails come first

The hosted guide and the instructions for your own assistant follow the same rules. Students should leave a session knowing more about satellites, not distracted.

You can try a demo of the guide with prewritten answers on the home page and on every quest page. A free preview with menu questions only, no typing, is also on the table. It would allow about 10 questions per device per day, counted with a hashed identifier that changes daily.

  • Talks only about CubeSats, orbits, amateur radio, sensors, data and the quests.
  • Gives hints and asks questions instead of doing the work.
  • Says it is an SI assistant and never asks for names, schools, locations or contact details.
  • Sends unsafe topics to a trusted adult and flags them to the teacher.
  • Uses the Anthropic API under commercial terms, never a personal subscription.
  • Built to Anthropic’s safeguards for products used by minors, with a COPPA review before launch.

Help us shape this

The proposal is that anything left after API and hosting costs helps fund proposed in-person workshops, if partners agree. Price, benefits, limits and who runs it are still open. The full framework, with open questions for reviewers, is in the repository.
