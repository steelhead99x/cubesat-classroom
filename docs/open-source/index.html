Two ways to build in the open, both respected

Some open-source projects work with real-time AI assistants. Others accept only code and text written by people. Both are careful choices made by their communities. We learn from both, and we follow each project's own rules when we contribute to it.

Every level of learning and experience

This project is for first-time learners and for people with decades of engineering, teaching and radio experience, and for everyone in between. Ask beginner questions. Share a failed test. Review someone else's work. Write every line by hand, or work with an AI assistant and say so. Each of these is a real contribution.

How this project is built

CubeSat Classroom and its site work by hikd.ai use human-driven coding agents. People direct the agent, check its work and decide what ships, bringing hundreds of hours on this project and lifetimes of experience between them. Contributions that use AI say so and explain what the person checked, as the contribution guide asks. Contributions written entirely by hand are just as welcome.

Projects that welcome AI-assisted work

These projects let contributors use AI coding assistants and real-time AI tools, as long as a person takes responsibility for the result and says when a tool helped.

  • Linux kernel

    AI tools may help, but only a person can certify a patch. Contributions say which tool helped with an Assisted-by tag.

    Read the AI coding assistants guide

  • Fedora

    Contributors may use AI assistance. They stay accountable for their work and disclose significant AI help, for example with an Assisted-by commit trailer.

    Read the AI-Assisted Contributions Policy

Projects that accept only human-written work

These projects keep AI-generated code and text out of their own work, for reasons that include copyright, quality and the cost of review. Contributing to them means writing every line yourself.

  • Gentoo

    Content created with the help of AI language tools may not be contributed to Gentoo.

    Read the Council AI policy

  • NetBSD

    Code generated by a large language model is treated as tainted and cannot be committed without written approval from the core team.

    Read the Commit guidelines
