# Archived quests

These quests belonged to the Rev A bench-case test track for a Bambu Lab P1S. That case is no longer offered as a build, so they are kept here for history and are not part of the quest board (`quest check` reads only `quest/`). The current printed frame is the [AMSAT CubeSatSim frame with an Arduino payload](/hardware/amsat-cubesatsim/README.md).

3. [Print the shell and lid](m0/print-p1s-case-parts.md)
4. [Test the assembly fit](m0/test-p1s-case-fit.md)
5. [Review an improvement against the fit evidence](m0/improve-p1s-case.md)
