A **Raspberry Pi** is a credit-card-sized computer that runs Linux, made by Raspberry Pi Ltd. Unlike an [Arduino](../arduino/), it runs a full operating system, so it can handle cameras, networking and heavier software. In the deck's bench test, a Pi 2 sends live video over [915 MHz](../915-mhz/).
